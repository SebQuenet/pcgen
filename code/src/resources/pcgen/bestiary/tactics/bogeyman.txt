## Avant le combat

note: Profil
  Croque-mitaine, fée des cauchemars d'enfants, qui terrifie et se nourrit de la peur.
  Contact intangible +10 (1d6) ; bruit dans la nuit ; effroi ; déplacement par les ombres.

step: Des victimes la nuit
  do: Bruits dans la nuit pour les terrifier

## Ouverture

step: Une victime
  do: Effroi : terreur
  note: il préfère les enfants et ceux qui ont peur du noir ; la lumière le repousse

## Rounds suivants

step: Toujours
  do: Toucher les victimes terrifiées, puis disparaître dans une ombre

## Repli

step: Lumière vive
  do: Déplacement par les ombres
