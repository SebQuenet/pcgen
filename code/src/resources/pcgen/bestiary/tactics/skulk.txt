## Avant le combat

note: Profil
  Rôdeur caméléon, humanoïde lâche à la peau changeante, qui vit dans les bas-fonds des villes et assassine dans le dos.
  Épée courte +2 (1d6, 19-20) ; dague lancée +4 ; attaque sournoise +1d6 ; peau caméléon ; pas camouflé.

step: Une proie isolée dans les ruelles
  do: Se fondre dans les murs et la suivre

## Ouverture

step: La proie lui tourne le dos
  do: Épée courte avec attaque sournoise

## Rounds suivants

step: Toujours
  do: Frapper puis disparaître dans le décor

## Repli

step: Il est repéré ou blessé
  do: Fuir et se fondre dans les murs
