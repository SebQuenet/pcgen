## Avant le combat

note: Profil
  Collecteur d'ombres, petite fée du Premier Monde (Int 15), qui vole les ombres des gens pour sa collection. Une victime sans ombre s'affaiblit et devient triste.
  2 griffes +15 (1d6+2) ; vol d'ombre ; RD 10/fer froid, RM 19 ; il se cache dans les ombres.

step: Une victime
  do: Approcher dans l'ombre, sans bruit

step: Une ombre remarquable
  do: La suivre pendant des jours

## Ouverture

step: La victime
  do: Voler son ombre

## Rounds suivants

step: Toujours
  do: Griffes, puis disparaître dans une autre ombre

step: Une lumière vive
  do: Fuir : il ne peut plus se cacher

## Repli

step: Il est blessé
  do: Se fondre dans les ombres avec son butin
